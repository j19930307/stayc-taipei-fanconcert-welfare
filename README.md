# 2026 STAYC FAN CONCERT [Stay Closer] IN TAIPEI
## 粉絲福利中獎序號快速查詢系統

本系統彙整 2026 STAYC FAN CONCERT [Stay Closer] IN TAIPEI 官方公佈之 69 張福利圖片，共收錄 **2,725 筆**完整中獎序號資料。

### 功能特色
- 🔍 **即時搜尋**：輸入 9 碼購票中獎序號，即時過濾匹配福利。
- 🎯 **精確定位**：顯示序號對應之「票價區間」、「福利項目」、「該福利第幾張圖」、「圖片順序」與「欄/列位置」。
- 🏷️ **票價與項目篩選**：支援 7800 / 5800 / 4800 / 3800 / 2800 各票價與特定福利項目下拉篩選。
- 📱 **RWD 響應式設計**：支援手機與電腦瀏覽。

### 使用方式
開啟 `index.html` 即可離線或透過 GitHub Pages 直接查詢。
